**版本號：** `X.Y.Z` 的 **patch**（例如 **0.1.1**）留給該 minor 的 **bugfix**，不排新功能。新功能走下一個 **minor**（0.1.0 → 0.2.0 → 0.3.0）。

構想清單見 [backlog/INDEX.md](./backlog/INDEX.md)。排進某版後與該版 INDEX 雙向連結。
